# AI-Powered Document Assistant using RAG

An AI-powered document assistant built using Retrieval-Augmented Generation (RAG) for intelligent document querying and semantic search.

## Features

- Semantic document search
- AI-generated contextual responses
- RAG pipeline integration
- Efficient document retrieval using FAISS

## Technologies Used

-Python
- LangChain
- FAISS
- Sentence Transformers
- Ollama

## Future Improvements

-Web Interface
- Multi-document support
- Voice interaction
- Faster indexing
